Privacy Policy — Vnezapno Fact publisher

Last updated: October 11, 2026

Vnezapno Fact publisher (“the tool”) is an internal, single-user tool of the creator of the Vnezapno Fact channel (@vnezapno_fact). It is used only by the channel creator, only for the creator's own YouTube channel. See the home page.

YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to data processed by Google.

What data the tool accesses

  • With the creator's OAuth consent: upload videos to the creator's own channel, read the status of the creator's own videos (processing, restrictions, view counts), delete the creator's own videos, read comments on the creator's own videos and post replies approved by the creator.
  • With an API key: public data about trending Shorts (titles, view counts) to choose topics.

How the data is used and stored

  • The OAuth token is stored only on the creator's own computer and is never shared.
  • The tool stores only IDs, links and view counts of the channel's own videos in a local database on the creator's computer, to track what was published.
  • Comments of viewers are read only to show them to the creator and are not stored or shared.
  • No data is sold, shared with or disclosed to third parties. No data is used for advertising.
  • The tool has no website sign-in and does not use cookies or similar technologies on users' devices.

Deleting data and revoking access

Access of the tool to a Google account can be revoked at any time on the Google security settings page. Stored data is deleted on request, and in any case within 30 days after access is revoked.
